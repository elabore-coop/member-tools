===========================
membership_associate_member
===========================

get list of members with associate_member_id

Description
===========

Use get_all_members_of_associate_member to get the list of members who benefit of the susbcription of a specific member (in param)

Installation
============

Use Odoo normal module installation procedure to install
``membership_associate_members``.
